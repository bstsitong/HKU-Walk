# HKU Walk

A campus map and student guide for HKU students and visitors, built for COMP7506.

- React Native / Expo / TypeScript on Android and iPhone; Django backend, PostgreSQL on Supabase.
- Browsing, search, place details, routes, saved places, recent history and guides need no app account.
- Community contributions and personal review history require an app account. Existing secure sessions, password recovery, image upload, moderation and published-edit approval remain functional.
- The user explicitly requests parity with the existing approved HTML prototype, including its search and navigation interactions. Use that phone UI as the visual and interaction reference.
- Support Simplified Chinese, Traditional Chinese and English; remember the selection locally. Built-in UI/content changes language; user submissions retain their published wording.
- Map geometry, position, entrances, times and route steps remain demonstrations. Live GPS and surveyed navigation are deferred.
